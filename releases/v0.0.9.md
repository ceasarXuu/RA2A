# RA2A v0.0.9

## 重点更新

- 修复 Codex Desktop 已打开 session 的 UI 不实时刷新问题。RA2A 现在始终优先交给当前 Desktop owner 创建 turn；只有确认请求尚未投递时才回退受管 App Server，投递结果不确定时不会重试，避免重复 turn。
- 明确 Desktop IPC 的投递边界。连接、初始化或 Desktop 明确拒绝属于“未投递”，可以安全回退；请求写出后的超时、断连或缺少 turn ID 属于 `DELIVERY_UNKNOWN`，不会回退或重试。

本版本已完成 Windows 与 macOS 官方 Codex Desktop 的真实跨设备验证。macOS 在同一 session、同一 Desktop 与 daemon 进程下连续完成 20 轮远端注入：20/20 到达并完成，无缺失、重复 turn、writer 冲突或 UI 刷新退化；同一 session 的手动续聊验证也已通过。

## 已知问题

v0.0.9 在目标已有 active turn 时仍会再次调用 `turn/start`。后端可能接收消息，但 Desktop renderer 的 turn 状态会失配，表现为页面长期停在“思考中”，通常需要重启 App 才能恢复显示。修复已进入后续 `main`：active turn 使用 `turn/steer`，只有 Desktop 明确报告无 active turn 时才调用 `turn/start`。

完整测试、`go vet`、相关 race 测试以及 Windows、macOS、Linux 的 amd64/arm64 发布构建由 Release workflow 统一验证。
