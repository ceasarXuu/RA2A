# RA2A v0.0.13

## 重点更新

- 修复 managed Codex App Server 异常退出后无法自动恢复的问题。首次探测即识别已退出的受管进程并立即重启，避免请求持续失败直到下个周期。
- 新增 managed Codex host 的进程监视与自动重启：受管进程退出后按固定间隔自动拉起新进程，无需等待下一次请求触发；明确停止（`ra2a stop` / `ra2a exit` / daemon 关闭）时不再重启。
- managed host 异常退出时记录带 PID 与退出原因的 `event=managed_codex_host_exited` 日志，便于定位崩溃过程。

## 验证

- `go test ./...`
- `go vet ./...`
- 单元测试覆盖两类场景：已退出受管进程在首个请求前被重启；受管进程退出后无需请求即被主动重启。

Release workflow 将构建 macOS、Linux、Windows 的 amd64/arm64 产物，并生成 SHA-256 校验文件。
