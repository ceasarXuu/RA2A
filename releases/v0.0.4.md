# RA2A v0.0.4

## 重点更新

- 修复 App Server 抢占会话：默认仍走受管 App Server；遇到明确的 `active writer` 冲突时，macOS 改由 Codex Desktop 已有 IPC 启动回合，不转移 writer，用户可以继续在原 session 手动沟通。建连失败保持 `SESSION_BUSY`，写出后超时返回 `DELIVERY_UNKNOWN`，不会重试或重复注入。
- 修复设备发现：mDNS 已发现的节点不再因 sessions 健康探测超时而消失。`list_targets` 现在返回 `ready`、`degraded`、`unreachable`，并在降级时保留带 `sessionsStale=true` 的最近成功结果。

Desktop IPC 属于未公开接口，当前已在 macOS Codex App 实机验证；相关实现、测试和实验记录均在仓库公开，后续会跟踪上游协议变化。
