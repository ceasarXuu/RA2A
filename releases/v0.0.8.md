# RA2A v0.0.8

## 重点更新

- 修复 Windows daemon 生命周期与启动终端耦合的问题。RA2A 现在使用当前登录用户的 `Interactive + Limited` 计划任务直接托管 daemon，无需管理员权限，也不再依赖隐藏 PowerShell 循环或 HKCU Run。
- 增加可靠的故障恢复。登录触发器负责首次启动，每分钟健康触发器配合 `IgnoreNew` 保证运行中不产生第二实例，同时在 daemon 意外退出后自动恢复；电池供电时任务也会继续运行。
- 解决 Codex 沙箱与 Task Scheduler 之间的文件可见性差异。Windows 二进制迁移到 `$HOME\.local\bin`，配置统一到 `$HOME\.config\ra2a`；升级时会读取并迁移旧 `%LOCALAPPDATA%\RA2A` 配置，保留设备名称、node ID、PIN 和 Codex 路径。
- 改进 Windows 安装失败诊断。计划任务注册与启动错误现在会保留 PowerShell 的原始输出，便于直接定位权限、身份和任务定义问题。

本版本已在 rog306 的官方 Codex Desktop 环境完成真实验证：daemon 的父进程为 Task Scheduler `svchost.exe`，关闭启动命令后仍保持运行；强制结束 daemon 后，任务在下一次健康触发窗口创建新 PID 并恢复 `127.0.0.1:47321` 监听。Mac 端协议和消息格式未变化，可继续与 v0.0.7 互通。

全量测试、`go vet`、相关 race 测试、PowerShell 语法检查，以及 Windows、macOS、Linux 的 amd64/arm64 发布构建门禁均已通过。
