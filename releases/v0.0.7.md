# RA2A v0.0.7

## 重点更新

- 恢复局域网节点发现的完整生命周期。RA2A 现在消费 DNS-SD 的新增、更新、goodbye、删除和过期事件；peer 记录使用 30 秒有效期，并每分钟重新加载网络接口，避免节点退出、Wi-Fi 切换或系统唤醒后长期保留 ghost endpoint。
- 修复节点重启后的连接恢复。DTLS 在投递前握手失败时会刷新发现结果，并针对恢复后的端点安全重试一次；无论节点回到相同 IP/端口，还是使用新的动态端口，都不需要重启发送端 daemon。
- 将默认 README 调整为英文并保留完整简体中文版本；安装契约测试现在分别验证两种语言，持续保证正式 Release 安装入口和“无需 Git/Go”承诺不会漂移。

本版本已在 rog306 Windows 与 macmini-m4 之间完成真实生命周期验收：Windows daemon 停止 35 秒后，Mac 移除了旧 peer；Windows 使用新 UDP 端点恢复后，Mac 无需重启即可重新发现并投递。重启前后两条唯一测试消息均只创建一个 user turn，目标列表没有大小写重复节点。

全量测试、`go vet`、LAN race 测试以及 Windows、macOS、Linux 的 amd64/arm64 构建门禁均已通过。
