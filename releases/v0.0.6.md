# RA2A v0.0.6

## 重点更新

- 新增 Windows Codex Desktop named-pipe transport。RA2A 现在使用 Microsoft `go-winio` 连接 `\\.\pipe\codex-ipc`，当目标 thread 已有 Desktop active writer 时，可由现有 Desktop owner 创建新 turn，不再返回“Windows named-pipe dialing is not part of the macOS experiment”。
- 保持既有 4 字节 little-endian framing、`initialize`、`thread-follower-start-turn`、active-writer fallback 和不确定投递不重试语义不变；Windows 与 Unix transport 通过 build tags 隔离。
- 补齐 Windows named-pipe 双向读写、context 取消、dial/read deadline、close、无服务端、服务端提前关闭及 discovery 插帧测试，并修正 Windows 上 Unix installer fixture 与路径断言的测试可移植性。

本版本已在 rog306 官方 Codex Desktop 上完成真实验证：Mac 向 Windows R8 session 的唯一消息返回 `accepted`、创建并完成 turn，随后原 R8 session 仍可正常本地继续沟通。全量测试、vet、race 以及 Windows/macOS/Linux 的 amd64/arm64 构建门禁均已通过。
