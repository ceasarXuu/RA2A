# RA2A v0.0.12

## 重点更新

- 新增 `ra2a stop` 和 `ra2a exit`：前者暂停服务并保留安装，后者终止并移除服务托管，便于用户明确控制 daemon 生命周期。
- 修复 RA2A managed App Server 在 daemon 重启或异常退出后可能残留并占用 session writer 的问题。每次启动使用独立 socket 与 owner lease，停止、重启和崩溃恢复时会回收完整进程组；Codex Desktop 不可用时明确失败，不再创建第二个 writer。
- 修复 Windows Codex Desktop 历史 session 的空 model 竞态。RA2A 会从 thread 或当前默认模型解析非空 model，并同时写入 Desktop owner settings 与 start request，避免 turn 同步接受后异步报 `The '' model is not supported`。
- 改进 Windows 安装器，在旧 `ra2a.exe` 被计划任务占用时先完成服务切换，再安全替换二进制。

## 验证

- `go test ./...`
- `go vet ./...`
- `go test -race ./internal/desktopipc ./cmd/ra2a`
- macOS 验证 managed App Server 的停止、重启和 daemon 崩溃恢复均不遗留旧进程或 owner lease。
- Windows 官方 Codex Desktop 跨设备验收通过：settings model 与实际 `turn_context.model` 均为非空，唯一 turn 正常完成，UI 无错误收敛，审批回信及原 session 手动续聊均成功。

Release workflow 将构建 macOS、Linux、Windows 的 amd64/arm64 产物，并生成 SHA-256 校验文件。
