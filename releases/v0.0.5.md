# RA2A v0.0.5

## 重点更新

- 修复设备重启或动态 UDP 端口变化后继续使用陈旧端点的问题。DTLS 握手失败时，RA2A 会通过独立 zeroconf Lookup 主动重新解析目标；仅当端点确实变化时，才使用同一 message ID 安全重试一次，不等待旧 mDNS 缓存自然过期。
- 修正投递错误语义。请求写出前的 DTLS 握手失败现在返回 `TARGET_UNREACHABLE`；只有握手完成、请求可能已写出但无法确认结果时才返回 `DELIVERY_UNKNOWN`，避免误导 Agent，也避免不安全的重复注入。

本次修复包含真实同 ID 节点重启与端口轮换测试、竞态检查，以及 macOS 自发现闭环和 Linux/Windows 交叉构建验证。
