# RA2A v0.0.10

## 重点更新

- 修复 active turn 中继续注入消息可能导致 Codex Desktop UI 长期停在“思考中”的问题。目标已有 active turn 时，RA2A 现在使用 `turn/steer` 将消息加入当前 turn；只有 Desktop 明确报告没有 active turn 时才创建新 turn。
- 保持严格投递语义：steer 或 start 请求写出后的超时、断连、取消及缺少 turn ID 均返回 `DELIVERY_UNKNOWN`，不会切换路径或自动重试，避免重复消息和重复 turn。
- Codex App 集成与现有配置、安装命令和局域网协议保持兼容，无需重新设置 node ID、名称或 PIN。

## 验证

- Windows 与 macOS 均完成官方 Codex Desktop active-turn 回归：空闲首条消息触发一次 start，执行中的 follow-up 触发一次 steer，两条消息进入同一个 turn，UI 无需重启即可实时更新并正常完成。
- 完成 Mac 与 rog306 两个 session 的双向长时间回归：20 轮交替问答、共 40 条 RA2A 消息，运行 8 分 27 秒；两方向均 20/20 到达，无缺失、重复、重试、writer 冲突或 UI 刷新退化。
- 双向回归结束后，两端均退出执行态并可在原 session 手动继续沟通；Desktop 与 daemon 进程保持不变。

Release workflow 将继续执行完整测试、`go vet`，并构建 macOS、Linux、Windows 的 amd64/arm64 产物与 SHA-256 校验文件。
