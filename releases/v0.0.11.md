# RA2A v0.0.11

## 重点更新

- 修复 Codex Desktop 消息注入后 UI 可能报错并停在“此轮内容无法显示”的问题。`thread-follower-start-turn` 与 `thread-follower-steer-turn` 现在始终携带兼容的 `text_elements: []` 字段，避免 Desktop 对缺失字段读取 `.length`。
- 保持 owner-first 投递语义：空闲 session 使用 `turn/start`，active turn 使用 `turn/steer`，不创建额外 writer，不改变原 session 的手动续聊能力。
- 补齐 macOS 官方 Codex Desktop 的实时文本元素验证，覆盖首条消息、同一 active turn 的 follow-up、完成收敛和手动续聊。

## 验证

- `go test ./...`
- `go vet ./...`
- macOS 与 Windows 的 Codex Desktop owner-first 回归通过：BASE/FOLLOWUP 同一 turn 实时可见，完成后 UI 收敛为 `completed`，原 session 可手动继续沟通。

Release workflow 将继续构建 macOS、Linux、Windows 的 amd64/arm64 产物，并生成 SHA-256 校验文件。
